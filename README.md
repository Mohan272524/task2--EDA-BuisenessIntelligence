📌 Project Overview

This project analyzes Walmart sales data using Python to understand sales trends and store performance.
The goal is to explore the dataset, identify patterns in sales, and understand how different factors like holidays, fuel price, temperature, and unemployment may affect sales.

The project includes data exploration, statistical analysis, SQL queries, and data visualization to generate meaningful insights.

 1️⃣ Exploratory Data Analysis 

This notebook explores the dataset and prepares it for analysis.

Main tasks:
* Loading and understanding the dataset
* Cleaning and formatting data
* Creating time-based features (Month, Year, Week)
* Checking missing values
* Visualizing basic sales trends

2️⃣ Multivariate Analysis 

This notebook studies how **multiple variables affect sales**.

Key analysis:
* Correlation between variables
* Impact of holidays on sales
* Relationship between sales and factors like temperature, fuel price, CPI, and unemployment
* Visualization using heatmaps and pair plots

3️⃣ SQL Analysis

SQL is used to query and analyze the data.
* Importing the dataset into SQLite
* Running SQL queries to find useful insights
* Calculating total and average sales
* Identifying store performance trends

4️⃣ Sales Dashboard 

This notebook creates **visual dashboards** to better understand sales performance.

Visualizations include:
* Total sales by store
* Sales trends over time
* Comparison of store performance
* Charts created using Matplotlib and Seaborn

📊 Dataset

The dataset used in this project is **Walmart Sales Data**, which contains:
* Store number
* Weekly sales
* Holiday flag
* Temperature
* Fuel price
* CPI
* Unemployment rate
* Date

🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQLite
* Jupyter Notebook

📈 Key Insights

* Sales vary across different Walmart stores.
* Seasonal patterns can be seen in weekly sales data.
* External factors like fuel price, temperature, and unemployment may influence sales.
* Visual dashboards help quickly understand store performance.
